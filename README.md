# Olá, eu sou o Felipe Lage 👋

**Engenheiro de Software · Backend, Cloud & DevOps · IA em produção**

Tenho mais de cinco anos de experiência construindo sistemas para logística
crítica — onde sistema parado significa navio esperando no porto. Trabalho de
ponta a ponta: desenho APIs, cuido da infraestrutura na nuvem e acompanho de
perto o que entrego rodando.

Alguns capítulos dessa história: liderei uma migração de EKS para ECS que
derrubou a fatura AWS em cerca de 30%, coloquei agentes de IA em produção de
verdade e hoje construo um ERP do zero — backend em Java/Spring, frontend em
Vue.js e infra na AWS.
