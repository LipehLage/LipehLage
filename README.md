# Olá, eu sou o Felipe Lage 👋

Sou engenheiro de software e passei os últimos cinco anos construindo
sistemas para logística crítica — onde sistema parado é navio esperando no
porto. Trabalho de ponta a ponta: desenho APIs, cuido da infraestrutura na
nuvem, coloco IA em produção e acompanho de perto o que entrego rodando.

Hoje construo um ERP do zero com Java/Spring e Vue.js. Nas horas vagas,
transformo lições que aprendi em produção em projetos abertos — são os repos
fixados aqui embaixo, cada um com o README contando a decisão por trás.
